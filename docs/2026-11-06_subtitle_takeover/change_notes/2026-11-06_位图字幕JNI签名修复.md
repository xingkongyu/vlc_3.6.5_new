# 2026-11-06 位图字幕 JNI 回调注册失败修复

## 主题

3.6.5 重建版 `libvlcjni.so` 的 `onSubtitleBitmaps` JNI 方法描述符多写一个 `I`，
导致 `GetMethodID` 恒返回 NULL，位图字幕回调**从未注册进 core**，
字幕一直退回 VLC 内置渲染上屏（App 侧 ImageView 接管完全没生效）。

## 现象（真机 1cf675004a230e19，播 PGS 字幕 MKV）

- logcat 只有 4 条 `VLCSubBitmap: bitmap listener cleared (observe)`，
  **从无** `VLCSubBitmap: bitmap listener registered (takeover)`。
- App 侧日志文件 `app_2026_11_05_21_14_24.log` 却反复打印
  `bitmap listener registered (listenerOnly=true, 由 App ImageView 绘制)`（假成功）。
- `VLCSubFix: REDRAW order=...` 说明字幕仍在 `display.c` 内置路径上屏。
- `VLCSpuTrace` 正常：PGS(bdpg) x3 → SELECTED → subpic->vout regions=1 text=0。

## 定位过程

1. `VlcVideo.java` 已确认接管开关默认 `true`、init 调用 `setBitmapSubtitleMode(true)`、
   `ensureBitmapListener()` 幂等注册；`VideoActivity2` 用 `VlcVideo` 且未覆盖开关。
   App 侧实现本身完整。
2. App 日志走 `LogUtils.d`（release 写文件、`DEBUG=false` 时不进 logcat），
   所以"注册成功"只能在文件里看到；core 侧日志反而暴露了真相。
3. JNI 桥 `nativeSetSubtitleBitmapListener` 第一行无条件
   `vlc_spu_set_bitmap_listener(NULL, NULL, false)` → 每次调用必打 `cleared (observe)`；
   只有末尾 `GetMethodID` 成功后才会再调注册并打 `registered (takeover)`。
   **缺 `registered` 说明卡在 `GetMethodID`。**
4. 对比 AAR 内 `libvlcjni.so` 的签名字符串：

   | AAR | 签名字符串 |
   | --- | --- |
   | `libvlc-release-20261102_112606.aar`（正式版基线） | `([[B[IIIJJ)V` ✅ |
   | `libvlc-release-20261105_180341.aar` | `([[B[IIIIJJ)V` ❌ |
   | `libvlc-release-20261105_182029.aar` | `([[B[IIIIJJ)V` ❌ |
   | 设备 `base.apk` 内 `lib/armeabi-v7a/libvlcjni.so` | `([[B[IIIIJJ)V` ❌ |

5. 基线 AAR `classes.jar` 里接口类 `SubtitleBitmapListener.class` 的方法描述符为
   `([[B[IIIJJ)V`，即
   `onSubtitleBitmaps(byte[][] rgba, int[] rects, int videoWidth, int videoHeight, long startMs, long stopMs)`。
6. 重建版多一个 `I` → 找不到方法 → `NoSuchMethodError` 被
   `if (!gref || !mid) { ExceptionCheck/ExceptionClear; return; }` 静默吞掉，
   Java 层 try-catch 感知不到，于是打印假成功日志。
   core 侧 `spu_user_params.pf_bitmap` 始终为 NULL，
   `SpuBitmapBridgeNotify()` 命中 `if (!pf || !b_only) return false` → 不接管。

## 修改内容

文件：`libvlcjni/libvlc/jni/libvlcjni-mediaplayer.c`
位置：`Java_org_videolan_libvlc_MediaPlayer_nativeSetSubtitleBitmapListener` 内，
`GetMethodID` 的签名参数（约 1529-1530 行）。

改前：
```c
    jmethodID mid = (*env)->GetMethodID(env, clazz, "onSubtitleBitmaps",
            "([[B[IIIIJJ)V");
```
改后：
```c
    jmethodID mid = (*env)->GetMethodID(env, clazz, "onSubtitleBitmaps",
            "([[B[IIIJJ)V");
```
